# Journey — Development Roadmap

This roadmap describes proposed work. Items are not complete unless explicitly marked complete in the repository.

## Phase 0 — Product validation
- [ ] Interview explorers, event organisers, and local providers.
- [ ] Select one initial launch category and geography.
- [ ] Validate the discovery-to-enquiry problem.
- [ ] Sketch and test low-fidelity user flows.

## Phase 1 — Foundation
- [ ] Create Next.js + TypeScript application.
- [ ] Configure linting, formatting, and environment validation.
- [ ] Set up PostgreSQL schema and migrations.
- [ ] Implement authentication and role-aware access.
- [ ] Add responsive design system and navigation.

## Phase 2 — Core discovery MVP
- [ ] Build experience feed and category browsing.
- [ ] Add location and category filters.
- [ ] Build experience detail pages.
- [ ] Add provider profiles and provider attribution.
- [ ] Implement saves and follows.
- [ ] Add provider enquiry workflow.

## Phase 3 — Trust and operations
- [ ] Add report and moderation workflow.
- [ ] Add provider verification review process.
- [ ] Add clear sponsored-content labels.
- [ ] Add listing correction and takedown process.
- [ ] Add basic analytics and audit events.

## Phase 4 — Pilot and iterate
- [ ] Run a small closed pilot.
- [ ] Measure discovery, save, and enquiry conversion.
- [ ] Fix usability and reliability issues.
- [ ] Document learnings and revise product scope.

## Later, only after validation
- [ ] Ticketing and booking integrations.
- [ ] Payments and refunds.
- [ ] Personalised recommendations.
- [ ] Organiser campaign tools.
- [ ] Native mobile applications.
